Archives are **`.rar`** — extract with WinRAR or 7-Zip before opening. Each unpacks to the source data and the `.pbix` report file; open the `.pbix` in Power BI Desktop.

---

## How to use this repo

- **Revising** — start with a cheat sheet, then work an interview PDF on the same topic. Reading order beats file order.
- **Building** — extract a project archive, open the `.pbix`, and reverse-engineer the measures rather than the visuals. The DAX is where the thinking lives.
- **Blank page** — pick a dataset you did not build and rebuild one page of it from scratch.
